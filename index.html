Rust API

Dataset 2026-11 - 2026-11-07T05:51:22+00:00

Unofficial, read-only API for Rust game data. Not affiliated with Facepunch.

Quick start

# Metadata
curl -s https://haxxorhardy.github.io/rust.api-site/v1/meta.json

# A single item
curl -s https://haxxorhardy.github.io/rust.api-site/v1/items/raw-beef.json

# All items (summaries)
curl -s https://haxxorhardy.github.io/rust.api-site/v1/items/index.json

# Raid costs for every building block
curl -s https://haxxorhardy.github.io/rust.api-site/v1/building/raid-costs.json

Every path ends in .json. Query parameters are only available on the optional worker; the static build ships precomputed views (by-category, craftable, by-tech-tree, ...).

Explorer

Searches the complete dataset in your browser. The search index (v1/search/index.json) is downloaded once and evaluated locally.
