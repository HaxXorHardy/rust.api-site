Rust API

Snapshot 2026-11 - 2026-11-05T05:52:09+00:00

Inoffizielle, read-only API auf Basis eines archivierten Snapshots von rusthelp.com. Keine Verbindung zu Facepunch oder rusthelp.com.

Was ist das?

Ein statischer Dateibaum mit JSON-Ressourcen und optional einem Cloudflare Worker fuer Suche und Filter. Alle Details liegen als Datei auf einem CDN, deshalb sind sie schnell, cachebar und brauchen keinen Server.

  • 2026-11 Snapshot
  • Items, Building, World, Monumente, Skins, Updates, Befehle
  • Kein API-Key, CORS offen, ETag und 304

Erste Schritte

# Metadaten
curl -s https://haxxorhardy.github.io/rust.api-site/v1/meta.json

# Ein Item
curl -s https://haxxorhardy.github.io/rust.api-site/v1/items/raw-beef.json

# Alle Items (Summaries)
curl -s https://haxxorhardy.github.io/rust.api-site/v1/items/index.json

# Raid-Kosten aller Bauteile
curl -s https://haxxorhardy.github.io/rust.api-site/v1/building/raid-costs.json

Alle Pfade enden auf .json. Query-Parameter gibt es nur beim Worker; statisch sind die wichtigsten Ansichten vorgebaut (by-category, craftable, by-tech-tree).

Explorer

Durchsucht den kompletten Datensatz direkt im Browser. Der Suchindex (v1/search/index.json) wird einmal geladen und lokal ausgewertet.
